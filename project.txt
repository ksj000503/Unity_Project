방치형 게임 - 메이플키우기 모작

## 컨셉
- 캐릭터 이미지: 추후 전달 예정
- UI: Claude가 제작, 임시 이미지 추후 전달 예정
- 나머지 세부사항은 협의해서 결정

## 코드 스타일 규칙
- 단순하고 읽기 쉽게 작성 (단, 기능 생략·대충 구현 절대 금지)
- 요구 기능은 전부 정확히 동작, 필요한 예외처리 빠짐없이 처리
- 지금 당장 불필요한 추상화·디자인패턴·미래대비 코드 금지 (YAGNI)
- 함수는 짧게, 변수/함수 이름은 명확하게
- 스크립트 한 개당 역할 한 가지
- 주석은 '왜' 이렇게 했는지만 짧게, 뻔한 내용은 달지 않음
- 여러 구현 가능성이 있으면 시간 복잡도 계산 후 더 빠른 알고리즘 채택
